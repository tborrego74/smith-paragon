# Smith-Paragon Partners

Concept flagship site for Smith-Paragon Partners, LLC (Denver, CO).

Static site. No build step. `index.html` loads three.js r128 from cdnjs and fonts from Google Fonts.

Run locally: `python3 -m http.server 8080` then open http://localhost:8080.

Deploy: import this repo in Vercel as a static project (Framework preset: Other, no build command, output directory `.`).

Placeholders (gold dashed) still need real content: headshots, case studies, contact details, booking link, target industries.
